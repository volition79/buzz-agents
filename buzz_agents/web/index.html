12자 이상. 서버 비밀번호와 별도로 정하는 설정 화면용 비밀번호입니다.

설정 화면 접근 복구

Docker Manager에서 buzz-agents를 펼치고 portal의 터미널을 여세요. 아래 명령을 실행한 후 관리 → 로그에서 portal의 최신 「Buzz recovery code」를 복사하세요.

python -m buzz_agents.portal_recover

60분간 한 번만 유효합니다. 봇·작업 파일·AI 인증·Windows 연결은 유지됩니다. 기존 브라우저 로그인과 미사용 연결 파일은 무효가 됩니다.

코드가 없거나 만료되었나요? · 처음부터 다시 시도

아직 비밀번호를 정하지 않았다면 portal 컨테이너를 재시작하고 최신 로그의 새 코드를 사용하세요. 컨테이너별 재시작이 보이지 않으면 portal 터미널에서 아래 명령으로 새 코드를 발급할 수 있습니다.

python -m buzz_agents.portal_recover

이미 설정을 마쳤다면 재시작해도 비밀번호가 초기화되지 않습니다. 기존 비밀번호로 로그인하거나 「접근 복구」를 이용하세요. 재시작하면 브라우저 로그인과 미사용 Windows 연결 파일은 만료됩니다. 로그의 코드·링크는 다른 사람에게 공유하지 마세요.

02 / WINDOWS BUZZ

한 번 연결하면 끝.

연결 파일을 내려받아 압축을 풀고 Buzz-VPS-Connect.exe를 실행하세요. 그다음 Buzz를 다시 열고, 봇의 실행 위치에서 Hostinger VPS — HTTPS를 선택하세요.

연결 파일은 10분간 한 번만 사용할 수 있습니다. 만료·실패 시 새 파일을 받으세요. 연결을 마친 PC는 파일이 만료되어도 계속 사용할 수 있습니다.

실패·재연결·다른 PC 추가

만료되었거나 사용한 파일이면 새 연결 파일을 받아 압축을 모두 푸세요. 같은 PC에서 프로그램을 다시 실행하면 기존 연결을 확인합니다. 재연결하려면 Buzz를 종료한 뒤 프로그램에서 「재연결」을 선택하세요. 다른 PC는 새 파일로 연결합니다. 저장 실패 메시지에 장치 ID가 나오면 아래 목록에서 해당 ID의 연결만 해제한 뒤 다시 시도하세요. 연결 해제는 VPS의 봇이나 작업 파일을 삭제하지 않습니다.
